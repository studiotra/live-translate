Live Translate

Meeting captions in three languages.

Korean, English, and Japanese are recognized as people speak. Each language gets its own screen, and each screen can read the translation aloud.

The Mac install file will be attached to this button with the first public build.

  1. 01

    Download the app

    Install it on the Mac you use in the meeting. The first time, right-click the app and choose Open.

  2. 02

    Create your own API keys

    Make a key at Deepgram for speech, and an API key at OpenAI for translation. A ChatGPT subscription is separate from API credit. Set a spending limit on each account.

  3. 03

    Paste the keys into the app

    Open Live Translate, paste both keys under API keys, and press Save keys. They stay on that Mac.

Audio from the meeting is sent to Deepgram. The text is sent to OpenAI for translation and, when you stop, for a summary. This page does not collect keys or accounts.
